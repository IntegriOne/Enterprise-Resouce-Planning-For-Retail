Draft ini mendefinisikan pekerjaan desain; **belum ada mockup pixel-perfect, Figma link atau hasil usability yang dijalankan**.

Antarmuka merchant **tidak** harus menampilkan nama 13 management. Gunakan menu: Dashboard, Produk, Pembelian, Supplier, Stok, Penjualan, Keuangan, Pelanggan, Channel Integrations, Support, dan Pengaturan. Hak akses menyebabkan menu/aksi disembunyikan **dan** backend tetap memeriksa grant.
