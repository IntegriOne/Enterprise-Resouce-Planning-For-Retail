- Model `principals`/`attributes`/access request pada pedoman konseptual HEAD berbeda dari skema `users` dan 16 tabel runtime IAM; perlu keputusan penyelarasan desain sebelum migrasi. `agents/principals.md` sedang terhapus dalam working tree oleh perubahan lain pada audit nomor 12.

- Tes bufconn 81 RPC masih memakai transactor mock; belum ada pembuktian RPC→PostgreSQL untuk rollback sesi/outbox, concurrent MFA, dan perubahan grant/revoke sampai Redis lintas instance. Klaim "seluruh RPC tersentuh tes" tidak berarti seluruh business flow sudah terverifikasi.
- Pengiriman email belum memakai outbox tahan gangguan. Cakupan historis statement handler 69,4% dan service 62,3%; cabang fault injection repository belum lengkap. Pengujian E2E lintas-service yang memanggil `createFixtureUser(..., "EMPLOYEE", ...)` tanpa `worker_id` + sesi MFA saat ini tertahan kontrak baru HRM (`CreateEmployeeUserInput.worker_id: ID!` + `MFAAuthenticated` ketika `HRM_GRPC_ENABLED=true`).
- Konfigurasi deployment produksi (`APP_ENV=production` dan mTLS internal gRPC) pada lingkungan staging/production nyata.
- Integrasi layanan domain hilir lain (HRM, Procurement, Commerce, dll.) terhadap event/lookup IAM serta pendaftaran manifest domain masing-masing ke `backend/shared/rbac/catalogs/{management}.json` mengikuti fase berikutnya.
