# Uji browser respons detail unit yang terlambat

Chrome membuka dua unit dari fixture Enterprise Foundation melalui HTTPS. Tes menahan permintaan detail Recruiting, menutup panel, membuka Commerce Ops, lalu melepaskan permintaan lama. Panel tetap menampilkan Commerce Ops setelah respons lama selesai. Grant uji diterapkan melalui GraphQL IAM.

TypeScript, ESLint untuk komponen terkait, dan build frontend lulus.
