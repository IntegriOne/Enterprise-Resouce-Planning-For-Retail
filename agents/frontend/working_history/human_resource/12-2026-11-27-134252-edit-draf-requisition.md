# Form edit draf requisition

Detail requisition menampilkan aksi edit untuk draf dan pemilik izin GLOBAL `human_resource.requisitions.update`. Form menampilkan nilai tersimpan dengan label bisnis dan mengirim perubahan melalui `updateRequisition`. Nomor requisition hanya bisa dibaca.

Uji Chrome melalui HTTPS memverifikasi pembuatan draf, nilai awal edit, penanganan penyimpanan tanpa perubahan, patch jumlah kebutuhan, dan hiring manager yang tetap tersimpan.
