# Referensi bisnis pada detail requisition

Panel detail menampilkan posisi, lokasi Enterprise Foundation, serta rencana dan lini tenaga kerja bila referensinya terisi. Jenis kebutuhan dan kategori memakai label yang sama dengan form. Status dan jumlah memakai detail terbaru setelah query berhasil.

Chrome lewat HTTPS membuktikan ketiga referensi masih terlihat dengan label bisnis setelah pengajuan. TypeScript, lint direktori terkait, dan build image lulus.
