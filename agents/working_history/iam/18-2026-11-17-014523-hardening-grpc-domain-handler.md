# Hardening IAM gRPC

Meninjau alur domain hingga handler untuk permission, role, group, session, user/auth, bootstrap, dan proof internal. Memperbaiki namespace serta konsistensi permission, penolakan delete permission yang masih digunakan, propagasi error outbox sesi, validasi status pemilik sesi dan recovery epoch, pencatatan actor dari caller terverifikasi, serta bypass MFA pada RPC sesi. Kontrak proto diperbarui dan digenerate ulang. `go fmt`, `go vet`, seluruh unit test IAM dengan `-race`, dan build image Docker lulus. Container IAM development direstart dan sehat; smoke health, penolakan RPC tanpa HMAC, serta query GraphQL publik lulus. E2E login dan matriks Query/Mutation selain `TestQueryPermissions` lulus; tes filter permission Gateway memakai resource lama `users` dan perlu diselaraskan menjadi `iam.users`. Validasi target scope lintas owner masih perlu diuji. Detail ada di audit IAM nomor 3 dan laporan E2E IAM nomor 1.
