# Kode periode pada PDF slip gaji

PDF HRM menampilkan kode periode bisnis beserta rentang tanggal. Jika kode kosong, PDF tetap menampilkan rentang. Tes ekstraksi teks dengan DejaVu Sans membuktikan kode tampil dan PDF tetap identik saat urutan input berubah. Race detector dan go vet lulus untuk paket renderer.
