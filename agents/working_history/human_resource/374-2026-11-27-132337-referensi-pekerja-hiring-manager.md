# Referensi pekerja hiring manager

Detail requisition memetakan principal tersimpan ke pekerja bila tautannya unik. Gateway menggunakan GID pekerja untuk detail dan Relay Node sehingga UI bisa membaca label melalui query pekerja. Uji gRPC dan HTTPS lulus. [Bukti](../../e2e/gateway/165-hrm-query-pekerja-hiring-manager-requisition.md).
