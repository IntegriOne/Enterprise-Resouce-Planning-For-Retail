# Ikat penerbitan slip ke run payroll

HRM mempertahankan ID run dari event Finance saat setiap hasil diproses dalam transaksi. Jika hubungan hasil dengan run berubah sejak daftar dibaca, HRM menolak hasil sebelum mengakses verifier Finance atau menyimpan PDF ke DRM. Tes regresi race dan suite gRPC Payroll PostgreSQL lulus.
