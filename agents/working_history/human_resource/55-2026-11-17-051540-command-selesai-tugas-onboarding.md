# Command selesai tugas onboarding

RPC `CompleteOnboardingTask` ditambahkan dengan permission sensitif tersendiri, validasi pekerja/plan, port bukti versi DRM, transaksi dan outbox atomik. Tes unit, validator, gRPC→PostgreSQL disposable, race, vet, build, generator proto serta container HRM sehat lulus. Adapter DRM belum tersedia; runtime produksi tetap `Unavailable` dan PIC non-worker tetap tertutup. Audit HRM nomor 39 serta catatan kontrak DRM mencatat batasnya.
