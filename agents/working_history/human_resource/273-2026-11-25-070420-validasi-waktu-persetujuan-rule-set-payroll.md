# Validasi waktu persetujuan rule set payroll

Kalkulasi menolak rule set dengan waktu persetujuan kosong atau di masa depan sebelum memanggil adapter. Tes service payroll dan regresi gRPC PostgreSQL dengan race detector serta go vet lulus. Regresi yang dijalankan mencakup jalur kalkulasi normal dengan rule set yang telah disetujui.
