# Penutupan requisition melalui GraphQL

Gateway menyediakan closeRequisition dengan izin sensitif di katalog IAM. HRM mempertahankan aturan state open dan ketiadaan proses rekrutmen aktif. Uji HTTPS membuktikan penutupan, konflik untuk state salah dan pengulangan, serta satu event penutupan. Approval dan pembukaan di stack uji memakai fixture bukti anggaran.
