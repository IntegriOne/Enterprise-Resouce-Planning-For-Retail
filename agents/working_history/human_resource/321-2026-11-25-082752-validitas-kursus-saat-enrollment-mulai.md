# Validitas kursus saat enrollment mulai

Pemeriksaan enrollment menggunakan tanggal mulai ketika memeriksa batas akhir validitas kursus. Tes gRPC PostgreSQL mencakup assignment sebelum kedaluwarsa, start setelah kedaluwarsa, dan keberhasilan saat kursus kembali berlaku. Tes dengan race detector dan go vet lulus.
