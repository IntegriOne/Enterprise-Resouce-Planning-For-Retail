# Regresi HRM dan Gateway

Jalankan suite HRM ber-tag integration dengan race detector, PostgreSQL sementara, dan font renderer slip. Sebanyak 66 paket lulus pada sweep awal. Succession serta Workforce Planning menolak konfigurasi awal karena mensyaratkan nama database dan opt-in disposable. Kedua paket lulus saat diulang pada database baru yang memenuhi syarat. Race test dan vet Gateway lulus. Matriks wiring cocok dengan 28 Query, 11 Mutation dan 47 RPC pada schema dan proto.
