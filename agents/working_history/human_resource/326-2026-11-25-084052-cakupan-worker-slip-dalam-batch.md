# Cakupan worker slip dalam batch

Detail dan daftar memuat hasil berdasarkan ID hasil dan kumpulan ID pekerja dalam beberapa batch filter. Query tetap membawa cakupan pemilik pada setiap batch. Tes gRPC PostgreSQL membuktikan daftar berjalan dengan 1.001 hubungan kerja tambahan. Race detector dan go vet lulus.
