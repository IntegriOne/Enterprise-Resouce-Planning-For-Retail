# Katalog resmi cuti

Manifest HRM memuat sembilan izin untuk kebijakan cuti, hak dan ledger, serta koreksi. Persetujuan, penolakan, posting dan penutupan ditandai sensitif. Tes kesesuaian memakai pemetaan RPC nyata agar izin leave_entitlements.post dapat dikaitkan dengan aksi gRPC post_leave_entry. Tes katalog, sinkronisasi IAM, dan adapter Gateway lulus.
