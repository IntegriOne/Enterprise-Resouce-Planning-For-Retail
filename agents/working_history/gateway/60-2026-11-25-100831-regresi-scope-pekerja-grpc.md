# Regresi scope pekerja pada gRPC HRM

Jalankan ulang tes gRPC Personnel memakai PostgreSQL uji, Redis TLS disposable dan race detector. Tes lulus untuk filter badan hukum dan perubahan revisi grant, termasuk penolakan setelah pencabutan sesi. Lingkungan uji sementara dibersihkan setelah tes. Uji akun IAM resmi melalui HTTPS masih terbuka.
