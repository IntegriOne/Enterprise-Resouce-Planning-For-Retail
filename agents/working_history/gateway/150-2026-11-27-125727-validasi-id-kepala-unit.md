# Validasi ID kepala unit

Gateway Enterprise Foundation memeriksa tipe Global ID pada create, update, assign, dan pencarian kepala unit. UUID mentah tetap diterima. Uji HTTPS membuktikan Global ID pekerja HRM diterima dan akun IAM ditolak sebagai jenis referensi yang salah. [Bukti HTTPS](../../e2e/gateway/159-ef-mutation-kepala-unit-id-pekerja.md).
