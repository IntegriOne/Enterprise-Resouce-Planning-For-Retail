# Wiring penambahan rincian workforce plan

Menambahkan `hrmCreateWorkforcePlanLine` dengan grant create global, sesi employee, dan CSRF. Gateway meneruskan nilai FTE dan estimasi biaya sebagai string desimal. Uji fixture mencakup pembuatan, konflik saat review, ID tidak valid, serta penolakan grant baca. Matriks operasi dan catatan IAM diperbarui.
