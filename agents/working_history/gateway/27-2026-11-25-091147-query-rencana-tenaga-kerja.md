# Wiring Query rencana tenaga kerja

Tambahkan detail dan daftar rencana tenaga kerja pada Gateway lewat Workforce Planning gRPC. Gunakan permission khusus rencana dan scope global atau badan hukum yang diverifikasi HRM. Daftar memakai total terotorisasi dari gRPC dan batas kompleksitas berdasarkan ukuran halaman. Tes GraphQL ke gRPC fixture memverifikasi detail, daftar dan pemisahan izin pekerja. Race test dan vet Gateway lulus.
