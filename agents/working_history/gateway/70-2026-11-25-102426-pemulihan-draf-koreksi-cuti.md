# Pencarian koreksi cuti berdasarkan kunci idempotensi

Tambahkan pencarian koreksi melalui kunci idempotensi untuk pemulihan setelah respons terputus. Query menerima tepat satu filter, yaitu ID hak cuti atau kunci idempotensi. Tes mencakup hasil cocok, respons dengan kunci berbeda, filter kosong dan filter ganda.
