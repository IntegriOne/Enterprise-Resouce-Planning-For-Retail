# Perbarui referensi draf requisition

Update GraphQL menambah input jabatan, unit, lokasi, posisi dan lini workforce plan. HRM mempertahankan pemeriksaan status dan konsistensi referensi. Uji HTTPS membuktikan edit jabatan dan unit, pengosongan lokasi, penolakan jenis ID salah dan edit setelah pengajuan. [Laporan](../../e2e/gateway/163-hrm-mutation-edit-referensi-requisition.md).
