# Baca detail transfer penugasan

Personnel menyediakan RPC baca per ID. Gateway menambah Query dan Relay Node dengan permission IAM terpisah. Uji gRPC PostgreSQL dan HTTPS memeriksa hasil detail, izin, resource ID, dan kondisi tidak ditemukan. [Laporan](../../e2e/gateway/156-hrm-query-detail-transfer-penugasan.md).
