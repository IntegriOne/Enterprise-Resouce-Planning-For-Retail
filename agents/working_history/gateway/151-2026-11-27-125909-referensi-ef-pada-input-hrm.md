# Referensi EF pada input HRM

Gateway menerima GID bertipe sesuai untuk referensi party, badan hukum, unit, dan lokasi. HRM tetap menerima UUID mentah ke gRPC dan menjalankan pemeriksaan owner. Uji HTTPS memverifikasi worker dan requisition. [Bukti](../../e2e/gateway/160-hrm-mutation-referensi-typed-id-foundation.md).
