# Pembuatan draf requisition

Gateway menambah `hrmCreateRequisition` dengan ID pekerja sebagai hiring manager. Katalog IAM mendaftarkan permission pembuatan. Uji HTTPS terisolasi memverifikasi provisioning IAM, unit EF, pembuatan draf, validasi input, dan pembacaan ulang. Panduan operasi mencatat label bisnis untuk UI. [Laporan uji](../../e2e/gateway/149-hrm-mutation-buat-draf-requisition.md).
