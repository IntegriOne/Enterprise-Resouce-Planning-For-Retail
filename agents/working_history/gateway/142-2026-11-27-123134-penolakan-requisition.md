# Penolakan requisition

Gateway menyambungkan penolakan requisition ke HRM dan menampilkan kode alasan pada detail. IAM menambahkan permission sensitif. Uji HTTPS membuktikan MFA, pemisahan kedua aktor, penolakan ulang, dan audit. [Laporan uji](../../e2e/gateway/151-hrm-mutation-penolakan-requisition-dua-aktor.md).
