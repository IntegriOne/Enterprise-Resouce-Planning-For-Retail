# Wiring PDF slip gaji privat

Query GraphQL meminta PDF lewat RPC privat HRM dengan izin SELF milik principal sesi. Tes Gateway membuktikan isi base64 dan no-store serta penolakan akses lain. Chrome menguji penerimaan byte fixture, tautan cetak, dan pencabutan URL dokumen. HRM, Gateway dan frontend development diperbarui.
