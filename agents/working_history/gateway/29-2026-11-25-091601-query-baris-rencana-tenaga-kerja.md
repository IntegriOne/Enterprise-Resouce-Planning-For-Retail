# Wiring Query baris rencana tenaga kerja

Hubungkan detail dan daftar baris rencana tenaga kerja ke Workforce Planning gRPC. Daftar menerima filter induk opsional dan memakai total terotorisasi dari HRM. Grant baca baris berdiri sendiri dan scope badan hukum diterapkan HRM terhadap rencana induk. FTE dipertahankan sebagai string desimal. Empat kasus integrasi GraphQL ke fixture lulus.
