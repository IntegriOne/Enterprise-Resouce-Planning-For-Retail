# Audit akses IAM untuk slip mandiri

Pemeriksaan baca-saja menunjukkan nol izin HRM pada IAM lokal. Temukan perbedaan akhiran izin self HRM dengan pengenal self-service bersama. Gateway dan HRM mengecek scope self eksplisit. Catat kasus yang harus diverifikasi saat IAM menerbitkan katalog resmi. [Status wiring](../../grpc/hrm/26-status-wiring-gateway-hrm.md#pemeriksaan-iam-untuk-izin-slip-mandiri).
