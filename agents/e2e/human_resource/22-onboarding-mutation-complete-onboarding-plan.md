# Finalisasi rencana onboarding

Tes memakai PostgreSQL sementara, policy dan verifier DRM tiruan, serta race detector.

| Kasus | Hasil |
| --- | --- |
| Tugas wajib belum selesai | FailedPrecondition |
| Tugas wajib tercatat selesai sebelum rencana dimulai | FailedPrecondition |
| Waktu penyelesaian tugas dipulihkan pada fixture | Finalisasi berhasil, waktu dan principal pelaku tersimpan |
| Finalisasi diulang | FailedPrecondition tanpa outbox tambahan |
