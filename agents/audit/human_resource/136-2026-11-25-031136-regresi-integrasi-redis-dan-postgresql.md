# Regresi integrasi HRM dengan Redis TLS dan PostgreSQL

Vet bertag integration menemukan sembilan salinan pesan Protobuf yang memuat mutex internal pada fixture Engagement, Leave, Payroll, Talent, dan Workforce Planning. Fixture kini memakai proto.CloneOf. Vet seluruh modul dan integrasi kelima paket lulus.

Suite serial dengan race detector diulang dari checkout setelah edit dan lulus pada 67 paket. PostgreSQL memakai database disposable dan Personnel menjalankan adapter sesi produksi dengan Redis TLS disposable. Gateway dan proyeksi IAM menggunakan fixture. Service produksi DRM dan Finance belum diuji.
