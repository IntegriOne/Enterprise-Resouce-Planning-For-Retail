# Waktu persetujuan payroll terminasi

Finalisasi offboarding memakai waktu server untuk memastikan persetujuan payroll terminasi sudah berlaku pada saat command berjalan. Persetujuan dengan waktu setelah waktu command ditolak sebagai konflik referensi. Tes unit meliputi penolakan waktu mendatang dan penerimaan waktu yang sama. Pemeriksaan hasil payroll untuk pekerja dan clearance pemilik tetap bagian dari command.
